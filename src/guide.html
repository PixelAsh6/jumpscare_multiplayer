Jumpscare Multiplayer - Setup Guide

This app uses Supabase (free) to connect all players. If you only want to join lobbies, you don't need this.

1Create a Supabase project
  1. Go to supabase.com and sign up
  2. Click New project
FieldValue
Namejumpscare-multiplayer (or anything)
Database passwordChoose one and save it
RegionPick the closest to you

Wait ~2 minutes for it to be ready.

2Run the SQL schema
  1. In your project dashboard, go to SQL Editor (left sidebar)
  2. Click New query
  3. Paste the entire SQL script below and click Run
CREATE TABLE lobbies (
  room_code TEXT PRIMARY KEY,
  host_id TEXT,
  admin_name TEXT DEFAULT '',
  chance REAL DEFAULT 1.0,
  video_url TEXT DEFAULT '',
  random_mode BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE players (
  id TEXT PRIMARY KEY,
  room_code TEXT REFERENCES lobbies(room_code) ON DELETE CASCADE,
  username TEXT,
  is_admin BOOLEAN DEFAULT false,
  online BOOLEAN DEFAULT false,
  last_seen TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE jumpscares (
  id BIGSERIAL PRIMARY KEY,
  room_code TEXT REFERENCES lobbies(room_code) ON DELETE CASCADE,
  player_id TEXT,
  username TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

ALTER TABLE lobbies ENABLE ROW LEVEL SECURITY;
ALTER TABLE players ENABLE ROW LEVEL SECURITY;
ALTER TABLE jumpscares ENABLE ROW LEVEL SECURITY;

CREATE POLICY "rl" ON lobbies FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "rl" ON players FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "rl" ON jumpscares FOR ALL USING (true) WITH CHECK (true);

INSERT INTO storage.buckets (id, name, public)
VALUES ('jumpscare-assets','jumpscare-assets',true)
ON CONFLICT DO NOTHING;
CREATE POLICY "up" ON storage.objects FOR INSERT
  WITH CHECK (bucket_id='jumpscare-assets');
CREATE POLICY "rd" ON storage.objects FOR SELECT
  USING (bucket_id='jumpscare-assets');
CREATE POLICY "upd" ON storage.objects FOR UPDATE
  USING (bucket_id='jumpscare-assets')
  WITH CHECK (bucket_id='jumpscare-assets');
CREATE POLICY "del" ON storage.objects FOR DELETE
  USING (bucket_id='jumpscare-assets');

ALTER PUBLICATION supabase_realtime ADD TABLE lobbies;
ALTER PUBLICATION supabase_realtime ADD TABLE players;
ALTER PUBLICATION supabase_realtime ADD TABLE jumpscares;
3Get your API keys
  1. In your project dashboard, go to Project Settings (gear icon at the bottom of the sidebar)
  2. Click API in the left menu
  3. Under Project URL, copy the URL (looks like https://xxx.supabase.co)
  4. Under Legacy API keys, copy the anon public key (starts with eyJ...)

Paste both values into the app Settings. Also set a Share Password in Settings — without it the app won't show a share string, and guests need the password to join.

4Share your lobby
  1. Create a lobby in the app with + New
  2. Copy the share string (starts with JUMPSCARE — it's encrypted)
  3. Send friends the string and your share password (separately)

How it works

  • Host creates a lobby - their username becomes admin
  • Guest joins via share string - same username = same admin on any device

Troubleshooting

ProblemFix
"Invalid API key"Double-check the anon key in Settings. Make sure you copied the anon key, not service_role.
No share string shownSet a Share Password in Settings first.
"Wrong password" when joiningAsk the host for the current share password — it must match exactly.
Players can't see each otherMake sure you ran the full SQL from Step 2 successfully.
Admin not working on other deviceMake sure you're using the same username.
